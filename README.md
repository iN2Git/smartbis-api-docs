# Smartbis API v2

Official API documentation for the Smartbis Loyalty Marketing platform.

## Documentation

Access the interactive Swagger documentation:

https://api.smartbis.com/docs/

## Features

- Customer management
- International customer addresses
- Sales registration
- Transaction history and refunds
- Coupons, categories and vouchers

## Authentication

The API uses Bearer Token authentication.

Base URL:

https://api.smartbis.com/v2
